# CareerGauge Resume AI Skills

这个仓库提供 CareerGauge 简历优化相关的 AI Skill 文件。

## 核心 Skill

- [careergauge-resumeAI-opt.md](skills/careergauge-resumeAI-opt.md)  
  中文版，适用于中文校招、实习、应届生和早期职业阶段的简历分析、JD 匹配、竞争力评价和候选版本优化。

- [careergauge-resumeAI-opt-eng.md](skills/careergauge-resumeAI-opt-eng.md)  
  English edition for using the same resume optimization workflow in English AI chat interfaces.

## 使用方式

打开对应 Markdown 文件，将其中的 Prompt 模板复制到 ChatGPT、Claude、DeepSeek、Kimi、Gemini 等 AI 对话界面，并上传或粘贴自己的简历与目标 JD。

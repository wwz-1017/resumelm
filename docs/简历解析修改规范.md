请帮我设计并实现一个“简历保存 / 简历管理”页面，用于展示用户已经创建或导入的简历文件。页面需要是原创设计，不要复制任何现有产品的 logo、图标、文案、配色或像素级布局，但可以参考现代 SaaS 后台常见的信息架构：左侧导航栏 + 顶部提示条 + 主内容区 + 卡片式文件管理。

页面目标：
用户进入后，可以看到自己的简历列表，可以新建简历、导入简历、编辑已有简历、复制简历、删除简历。整体风格要简洁、专业、适合 AI 简历产品。

布局要求：

1. 左侧固定导航栏，宽度约 220px，包含产品名称和 4 个导航入口：

   * 我的简历
   * 简历模板
   * AI 服务
   * 通用设置
     当前页面“我的简历”需要高亮。
2. 右侧为主内容区，背景使用浅灰白色或接近白色，整体留白充足。
3. 主内容区顶部放一个浅色提醒横幅，提示用户配置云端保存或备份路径，避免本地数据丢失。
4. 提醒横幅右侧放一个“前往设置”按钮。
5. 横幅下方是页面标题“我的简历”。
6. 标题右侧放两个操作按钮：

   * “导入简历”：次级按钮
   * “新建简历”：主按钮
7. 下方使用卡片网格展示简历，每张卡片宽度约 260-320px，高度约 320-380px。
8. 第一张卡片是“新建简历”入口，使用虚线边框、大号加号图标、标题和说明文字。
9. 已保存简历卡片包含：

   * 顶部预览区：显示简历缩略图；如果没有缩略图，则显示空白预览占位。
   * 底部信息区：显示简历名称、模板名称、最后更新时间。
   * 底部操作栏：编辑、复制、删除三个操作。
10. 删除操作使用危险色提示，但不要过度刺眼。

视觉风格：

1. 整体风格现代、克制、轻量，类似生产力工具或文档管理后台。
2. 不要使用截图中的品牌、logo、具体文案和完全相同的配色。
3. 推荐使用：

   * 主色：深蓝灰 / 靛蓝 / 墨黑蓝任选一种
   * 背景：#F8FAFC 或 #FAFAFA
   * 卡片：白色
   * 边框：#E5E7EB
   * 危险色：柔和红色
4. 卡片需要有圆角、细边框、轻微阴影，hover 时轻微上浮或边框变深。
5. 按钮需要有清晰的主次层级。
6. 页面整体不要拥挤，间距要舒适。

交互要求：

1. 点击“新建简历”后触发 createResume。
2. 点击“导入简历”后打开上传弹窗或文件选择器。
3. 点击“编辑”后进入简历编辑器。
4. 点击“复制”后复制当前简历，并生成新的简历卡片。
5. 点击“删除”前需要二次确认。
6. 如果当前没有任何简历，只显示“新建简历”卡片和空状态说明。
7. 支持响应式布局：大屏一行 3-4 张卡片，中屏 2 张，小屏 1 张。

数据结构建议：
每个简历对象包含：

```ts
type ResumeItem = {
  id: string
  title: string
  templateName: string
  updatedAt: string
  thumbnailUrl?: string
}
```
